# Режимы данных: полный, экономный, бесплатный

Платные коннекторы (vidIQ, NexLev, Apify) нужны только для **сбора данных**. Анализ — паттерны, диагнозы, сценарии, концепты — делается сам и от кредитов не зависит. Поэтому при нехватке кредитов меняется источник данных, а не качество выводов.

## Как выбрать режим (в начале работы)
1. Если пользователь сказал «без кредитов», «бесплатно», «кредиты кончились» → **бесплатный режим**.
2. Иначе проверь баланс, если есть инструмент (vidIQ `vidiq_balance`). Мало кредитов или ошибка лимита/оплаты у любого платного вызова → **экономный**, а при повторной ошибке → **бесплатный**. Переключайся молча, в ответе одна строка: «Часть данных собрана бесплатными способами».
3. Иначе → **полный режим** (как в `tools.md`).

## Экономный режим — тратить кредиты только на незаменимое
Платить стоит за: поиск outliers по нише, список похожих каналов, массовые транскрипты.
Не платить за то, что можно получить иначе:
- оценки заголовков и обложек → считай сам (`scripts/title_patterns.py`, `scripts/thumbnails.py` + чек-листы);
- генерацию заголовков и обложек → пиши сам;
- повторные запросы одних и тех же данных → сохраняй результаты первого вызова в файл в рабочей папке и переиспользуй в рамках разговора;
- транскрипт целиком → нужен только хук: бери 3–5 роликов, а не 10.

## Бесплатный режим — откуда брать данные
По убыванию качества:
1. **Выгрузка YouTube Студии** (только свой канал, самые точные данные: CTR, показы, удержание). Попроси пользователя: Студия → Аналитика → «Расширенный режим» → экспорт CSV, загрузить файл «Table data.csv». Обработка: `scripts/studio_report.py`.
2. **Данные от пользователя.** Попроси вставить в чат или файлом список роликов конкурента (название + просмотры), скриншоты вкладки «Видео» канала, отсортированной по популярности, или скриншоты обложек. С картинок данные читай сам и сохраняй в CSV для скриптов.
3. **Веб-поиск** (web_search / web_fetch / Exa, если подключён): поиск конкурентов и тем, названия роликов, обсуждения ниши, статьи о трендах. Цифры просмотров из поиска неточные — помечай их «≈».
4. **Обложки:** ссылка вида `https://i.ytimg.com/vi/<VIDEO_ID>/hqdefault.jpg` (ID — из ссылки на видео); если не открывается — попроси скриншоты.
5. **Транскрипт:** пользователь открывает видео → «…» под видео → «Показать текст видео» → копирует текст в чат. Достаточно первых 1–2 минут.

Обязательно скажи пользователю **конкретно**, что принести, одним коротким списком — не больше 3 пунктов, по приоритету.

## Скрипты (бесплатно, работают в среде выполнения кода)
Запускай из папки `scripts/` скилла (или скопируй папку в рабочую директорию):
- `outliers.py <csv>` — залетевшие ролики по ×медианы + список обычных для сравнения
- `title_patterns.py <csv>` — признаки заголовков: залетевшие vs обычные
- `thumbnails.py <папка>` — метрики обложек (яркость, контраст, насыщенность, загруженность, цвета), сравнение групп win/normal и сетки превью в мобильном размере
- `studio_report.py <Table data.csv>` — диагноз каждого ролика по CTR × удержанию

Формат CSV: колонки с названием и просмотрами обязательны, остальные по желанию (канал, дата, подписчики, ссылка). Названия колонок можно по-русски.
