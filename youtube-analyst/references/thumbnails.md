# Анализ обложек и поиск паттернов

## Как смотреть
Обложку видят размером со спичечный коробок в ленте, часто на телефоне. Оценивай так, как её увидит зритель: за полсекунды, в маленьком размере.

## Чек-лист разметки (для каждой обложки)
| Признак | Варианты |
|---|---|
| Главный объект | лицо / человек целиком / предмет / сцена / нет явного |
| Эмоция лица | шок, страх, радость, злость, задумчивость, нейтрально, нет лица |
| Размер объекта | занимает >40% кадра / 20–40% / мелкий |
| Текст | нет / 1–3 слова / 4+ слова |
| Текст повторяет заголовок? | да / нет (дополняет) |
| Цвет фона | тёмный / светлый / яркий насыщенный |
| Доминирующие цвета | 1–2 основных цвета |
| Контраст объекта с фоном | высокий / средний / низкий |
| Композиция | объект слева / справа / центр; «до/после»; сравнение двух вещей |
| Графика | стрелки, круги, обводка, эмодзи, нет |
| Интрига | есть «вопрос без ответа» (скрытый предмет, размытие, недосказанность) / нет |
| Читаемость в маленьком размере | да / нет |

## Поиск паттернов
1. Размечай 10–20 обложек залетевших роликов и 10 обложек обычных роликов (медианных) — канала пользователя или ниши.
2. Посчитай для каждого признака долю у залетевших и у обычных.
3. Паттерн = признак, который у залетевших встречается заметно чаще (разница ≥ 25 п.п.). Признак, одинаковый у всех, — просто норма ниши: его надо соблюдать, но он не даёт преимущества.
4. Проверь связку с заголовком: лучшие обложки обычно показывают то, о чём заголовок не говорит прямо, а не дублируют его.

## Формат вывода
Таблица: признак | у залетевших | у обычных | вывод.
Затем 3–5 правил для обложек этого канала в формате «делать / не делать».

## Концепт новой обложки
- Композиция (что где расположено)
- Главный объект и эмоция
- Цвета (2–3, с hex по возможности)
- Текст — не больше 3 слов, на языке аудитории
- Промпт для генерации изображения (на английском, подробный: стиль, свет, ракурс, фон, без текста — текст добавляется отдельно)
- Почему это сработает — ссылка на найденный паттерн
