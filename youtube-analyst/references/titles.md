# Анализ заголовков и поиск паттернов

## Разметка каждого заголовка
- Длина в символах (важны первые ~50: дальше обрезается на телефоне)
- Структура — к какому шаблону относится (см. ниже)
- Есть ли число, имя/бренд, «я»/личный опыт, вопрос, отрицание («никогда», «не делай»), крайность («самый», «худший»), срок/деньги
- Тип интриги: пробел в знаниях / конфликт / результат / предупреждение / сравнение
- Ключевое слово для поиска — в начале или нет

## Частые шаблоны (проверяй, какие работают именно в этой нише)
- «Я сделал X N дней — вот что случилось» (личный эксперимент)
- «Почему X на самом деле Y» (разоблачение / объяснение)
- «X против Y» (сравнение)
- «Никогда не делай X» / «Перестань делать X» (предупреждение)
- «Как X сделал Y за Z» (история успеха с конкретикой)
- «Самый X в мире» (крайность)
- «Что будет, если X» (гипотетика)
- «N вещей, которые…» (список)

## Поиск паттернов
Тот же принцип, что с обложками: сравни частоту шаблонов и признаков у залетевших и обычных роликов. Выпиши 3–5 шаблонов, которые реально выделяют победителей, с 2 примерами из ниши каждый.

## Как писать новые заголовки
- 5 вариантов, разные шаблоны из найденных рабочих
- До ~60 символов, суть в первых 40
- Обещание, которое видео точно выполняет (кликбейт без выполнения убивает удержание)
- Заголовок и обложка дополняют друг друга, а не повторяют
- По возможности проверь через `vidiq_score_title` и укажи оценку
