# Полный пакет (когда пользователь прислал только ссылку на канал)

Собери данные (SKILL.md, шаг 1), проведи анализ и выдай пакет строго в этом порядке. Без вступлений, без описания процесса, без технических деталей.

## 1. Диагноз канала
3–5 слабых мест, каждое с доказательством из данных: хуки, темы, упаковка, удержание, регулярность. Пример: «Хуки: 7 из 10 последних роликов начинаются с приветствия и рассказа о канале; у залетевших конкурентов результат или конфликт показан в первые 5 секунд».

## 2. Что исправить + тактики конкурентов
Для каждого слабого места — конкретное исправление и пример у конкурента (название ролика, ×медианы, ссылка).

## 3. Убойная тема следующего видео
Одна тема. Почему она: какие outliers её подтверждают, есть ли спрос (комментарии, поиск), чем угол отличается от уже снятого.

## 4. 5 заголовков с высоким CTR
Разные шаблоны из найденных рабочих паттернов ниши.

## 5. Сценарий
- **Хук 0–15 с** — дословный текст. Сразу результат/конфликт/интрига, без приветствий.
- **Поминутный план** — для каждой минуты: о чём говорим, какой B-roll/визуал, где удерживающий крючок («но дальше было хуже…»).
- **CTA** — один, естественный, ближе к концу, связанный с темой.
Длительность — под норму ниши (по медиане длительности залетевших роликов).

## 6. Концепт обложки
По шаблону из `thumbnails.md`: композиция, цвета, текст ≤ 3 слов, промпт для генерации изображения.
