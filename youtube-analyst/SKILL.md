# YouTube-аналитик

Цель — давать создателю контента выводы, на основе которых можно сразу действовать: что снимать, как назвать, как оформить обложку и почему. Каждый вывод опирается на реальные данные (просмотры, отношения, сравнения), а не на общие советы из интернета.

## Принципы

- **Данные, а не мнения.** «Обложки с лицом работают» — плохо. «8 из 10 залетевших роликов ниши имеют крупное лицо с эмоцией, у обычных роликов канала — 2 из 10» — хорошо.
- **Сравнивай победителей с обычными.** Паттерн имеет смысл, только если он чаще встречается у залетевших роликов, чем у средних. Иначе это просто норма ниши.
- **Без воды и технических подробностей.** Пользователю не нужно знать, какие инструменты вызывались и какие были ошибки. Только результат.
- **Отвечай на языке пользователя** (обычно русский). Заголовки и тексты для обложек — на языке аудитории канала.
- **Честность.** Если данных не хватило (инструмент недоступен, мало видео), скажи об этом одной строкой и работай с тем, что есть. Не выдумывай цифры.

## Шаг 0. Определи режим

| Запрос пользователя | Режим | Справка |
|---|---|---|
| Только ссылка на канал / «разбери канал» | **Полный пакет** (все режимы ниже кратко + пакет следующего видео) | `references/package.md` |
| «Найди залетевшие / вирусные / топовые ролики» | Outlier-поиск | `references/outliers.md` |
| «Разбери обложки», «что общего у превью» | Анализ обложек | `references/thumbnails.md` |
| «Разбери названия», «придумай заголовки» | Анализ заголовков | `references/titles.md` |
| «Кто конкуренты», «сравни с каналом X» | Конкуренты | `references/outliers.md` (раздел «Конкуренты») |
| «Что сейчас в тренде в нише» | Тренды | `references/tools.md` |
| «Что пишут зрители», «о чём просят» | Комментарии | `references/tools.md` |
| Загружен CSV из Студии / «почему мои видео не смотрят» | Диагноз своего канала (`scripts/studio_report.py`) | `references/data-modes.md` |
| «Разбери хук», транскрипт или «где теряю зрителей» | Аудит хука и удержания | `references/hooks.md` |

| Ссылка на одно видео | Разбор видео: метаданные, транскрипт хука, обложка, сравнение со средним по каналу | `references/thumbnails.md`, `references/titles.md` |

Прочитай `references/tools.md` и `references/data-modes.md` один раз в начале: первый — какой инструмент для чего, второй — как работать в экономном и бесплатном режимах, когда кредиты vidIQ/NexLev кончаются. Затем читай только справки нужного режима.

## Режим данных
Сначала определи режим по `references/data-modes.md`: **полный** (платные коннекторы есть и работают), **экономный** (кредитов мало — платить только за незаменимое) или **бесплатный** (кредитов нет — веб-поиск, данные пользователя, выгрузка Студии и скрипты из `scripts/`). Ошибка лимита или оплаты — не повод остановиться: переключись на следующий режим и продолжай.

Скрипты в `scripts/` (бесплатно, в среде выполнения кода): `outliers.py` — залетевшие ролики, `title_patterns.py` — паттерны заголовков, `thumbnails.py` — метрики обложек и сетки превью в мобильном размере, `studio_report.py` — диагноз роликов по CTR × удержанию. Используй их в любом режиме, если данные уже в таблице: подсчёты в коде точнее, чем на глаз.

## Шаг 1. Собери данные

1. Определи канал (ID / handle) и его нишу.
2. Возьми последние 30–50 роликов канала с просмотрами и датами. Посчитай медиану просмотров — это «норма» канала. Отдельно для Shorts и длинных видео: смешивать их нельзя.
3. Найди 3–7 конкурентов (похожие каналы) и их залетевшие ролики за последние 3–6 месяцев.
4. Для 10–20 лучших роликов ниши собери: название, ссылку на обложку, просмотры, отношение к медиане их канала, дату, длительность.
5. Для 3–5 самых сильных роликов возьми транскрипт первых 60 секунд — там хук.

Не трать вызовы впустую: если один инструмент уже дал нужное поле, не запрашивай его повторно другим.

## Шаг 2. Анализ

- **Outliers:** см. `references/outliers.md`. Главная метрика — во сколько раз просмотры выше медианы своего канала.
- **Обложки:** см. `references/thumbnails.md`. Смотри сами картинки, если можешь их увидеть; размечай каждую по чек-листу и считай частоты.
- **Заголовки:** см. `references/titles.md`. Размечай структуру, длину, триггеры; выделяй шаблоны.
- **Хук:** см. `references/hooks.md`.
- **Слабые места канала:** сравни ролики канала с залетевшими роликами ниши по темам, заголовкам, обложкам, хукам, длительности, частоте выхода.

## Шаг 3. Результат

Формат ответа по умолчанию (для полного пакета — шаблон в `references/package.md`):

1. **Главный вывод** — 2–3 предложения: что сейчас мешает каналу и что даст больше всего роста.
2. **Таблица залетевших роликов** — название, канал, просмотры, ×медианы, ссылка.
3. **Паттерны обложек** — таблица «признак → % у залетевших → % у обычных» + 3 вывода.
4. **Паттерны заголовков** — 3–5 рабочих шаблонов с примерами из ниши.
5. **Что делать** — конкретные действия по приоритету.
6. (если запрошен пакет) **Пакет следующего видео**.

Таблицы — только там, где есть цифры для сравнения. Остальное — короткая проза.
