# YouTube Analyst — скилл для Claude

Полный YouTube-аналитик внутри Claude: разбор канала, поиск залетевших роликов в нише, анализ обложек и заголовков с поиском паттернов, конкуренты, тренды, комментарии и готовый пакет следующего видео (тема, 5 заголовков, сценарий, концепт обложки).

## Что умеет
- **Outliers** — находит ролики, которые набрали в 3–10+ раз больше обычного для своего канала
- **Обложки** — размечает по 12 признакам и сравнивает залетевшие с обычными, выдаёт правила «делать / не делать»
- **Заголовки** — выделяет шаблоны, которые реально отличают победителей
- **Конкуренты** — таблица каналов и «пустые темы»
- **Свой канал по выгрузке Студии** — диагноз каждого ролика: слабая обложка/название, слабый хук или хит
- **Аудит хука** — переписанный хук и точки, где уходят зрители
- **SEO, Shorts, контент-план** — описание и таймкоды, нарезка Shorts из длинного видео, план на месяц, A/B-тест обложек
- **Пакет видео** — диагноз канала, тема, 5 заголовков, сценарий с хуком и B-roll, концепт обложки с промптом

## Что нужно
С коннекторами **vidIQ** / **NexLev** данные собираются автоматически. Когда кредиты кончаются, скилл сам переходит в экономный, а затем в бесплатный режим: веб-поиск, выгрузка YouTube Студии, скриншоты и списки от пользователя + встроенные Python-скрипты. Анализ от кредитов не зависит.

## Установка
**Claude.ai (браузер):** скачай `youtube-analyst.zip` из Releases (или запакуй папку `youtube-analyst` в zip) → Настройки → Capabilities → Skills → загрузить.

**Claude Code:**
```
git clone https://github.com/<твой-ник>/youtube-analyst-skill
cp -r youtube-analyst-skill/youtube-analyst ~/.claude/skills/
```

## Как пользоваться
Просто пришли Claude ссылку на канал — получишь полный пакет. Или попроси точечно: «найди залетевшие ролики в нише …», «разбери обложки канала …», «придумай 5 заголовков про …».

## Структура
```
youtube-analyst/
├── SKILL.md               — главный сценарий, выбор режима
├── references/
│   ├── tools.md           — какой инструмент для чего
│   ├── data-modes.md      — полный / экономный / бесплатный режимы
│   ├── outliers.md        — поиск залетевших роликов
│   ├── thumbnails.md      — чек-лист обложек и паттерны
│   ├── titles.md          — шаблоны заголовков и паттерны
│   ├── hooks.md           — аудит хука и удержания
│   ├── package.md         — пакет следующего видео
│   └── extras.md          — SEO, Shorts, контент-план, A/B, комментарии
└── scripts/
    ├── outliers.py        — залетевшие ролики по ×медианы
    ├── title_patterns.py  — паттерны заголовков
    ├── thumbnails.py      — метрики обложек + сетки превью
    └── studio_report.py   — диагноз по выгрузке Студии
```
